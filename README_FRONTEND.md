# Centinela 1.0

Single-screen demo console for the Centinela story.

## What is included

- `/console` for one-click normal, geo-impossible, velocity burst, risky merchant, and invalid transaction flows.
- Client-side latency display to show the separation between acknowledgment and analysis.
- Verification document upload with local identity-field extraction.
- A lightweight mirror of the Centinela contract, scoring rules, and evidence flow for demo use.

## Run it

```bash
npm run dev
```

Open [http://localhost:3000/console](http://localhost:3000/console).
